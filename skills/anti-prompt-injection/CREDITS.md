# Credits

The injection vector taxonomy (instruction override, roleplay/context manipulation, encoding and obfuscation, tool/exfiltration abuse, and secondary fetch chains) is adapted from [yaklang](https://github.com/yaklang)'s [`llm-prompt-injection`](https://www.skills.sh/yaklang/hack-skills/llm-prompt-injection) skill ([`yaklang/hack-skills`](https://github.com/yaklang/hack-skills) repo, licensed under the **MIT License**, which permits modification and redistribution with source attribution), inverted with Gemini Argon from an offensive red-teaming guide into a defensive detection and quarantine skill. Because the original repository documents how an attacker crafts and delivers prompt injection payloads, `anti-prompt-injection` reverses those exact mechanics into inspection steps and remote-download guardrails without depending on `hack-skills` at runtime; this file carries the source and license attribution that a direct dependency would otherwise provide.
